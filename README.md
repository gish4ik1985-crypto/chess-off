# Шахматный клуб «Молния» (проект chessoff, Godot 4.7)

Детская шахматная игра на русском: против ИИ с 25 уровнями, карта «Шахматной страны» (3 акта по 20 узлов),
турниры и база игроков, задачи (мат, вилка, связка и др.), «Дорога домой» — личный путь под слабые места игрока,
«Внимательность» (подсказки угроз, 50 уровней), «Школа», «Партии великих», дневник и индекс мастерства.
Игра подстраивается под игрока: «живая сложность», остановки Дороги из его ошибок.

## Запуск из исходников
Нужен Godot 4.7+. Открыть папку проекта в редакторе и нажать «Запуск» (F5), либо:

    godot --path .

## Проверки
Все сразу (около 2 минут):

    powershell -ExecutionPolicy Bypass -File run_tests.ps1            # всё
    powershell -ExecutionPolicy Bypass -File run_tests.ps1 -Quick      # без долгих
    powershell -ExecutionPolicy Bypass -File run_tests.ps1 -Only Rules # по части имени

Скрипт запускает проверки в песочнице (подменяет `APPDATA`), живые профили игроков не затрагиваются.
Путь к Godot берётся из переменной `GODOT`, иначе ищется в PATH, «Загрузках» и на рабочем столе.
По отдельности: `godot --headless --path . res://scenes/tools/<Имя>.tscn`.

## Веб-версия (GitHub Pages)
Готовая сборка лежит в `docs/` (Settings → Pages → ветка `main`, папка `/docs`). Пересборка (нужны шаблоны экспорта
той же версии, что и редактор):

    godot --headless --path . --export-release "Web" docs/index.html
    python web/post_export.py      # название «Шахматный клуб «Молния»» в манифесте приложения

Экран загрузки — свой (`web/shell.html`: печать клуба, русская полоса прогресса). Логотип — `assets/brand/seal.svg`
и `icon.svg`; после их смены один раз запустить `scenes/tools/MakeIcons.tscn`, чтобы пересчитать PNG-значки.

Сборка без потоков; профили игроков хранятся в браузере (IndexedDB), перенос между устройствами —
Настройки → «Сохранить профиль» / «Загрузить профиль». Шрифты лежат в `assets/fonts/` (в браузере системных шрифтов нет).

## Облако школы (Firebase, бесплатный тариф)
Общие аккаунты, таблица игроков с публичным рейтингом и перенос профиля на другой компьютер. Настройка один раз —
`firebase/setup.md` (ключи в `firebase_config.json`). Пока ключи пусты, игра работает только локально.
Другие игроки видят ник и турнирный рейтинг; статистика ходов и сильные/слабые стороны хранятся приватно.

## Структура
- `scripts/`, `scenes/` — игра; `scripts/tools/`, `scenes/tools/` — тесты и измерительные инструменты (в релиз не попадают)
- `assets/` — фигуры, звуки, шрифты; `theme/` — неоновая тема
- `notes/` — заметки и черновики; `archive/` — старые прототипы
- `deep-audit.md` — полный аудит проекта (05.10.2026)
