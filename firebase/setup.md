# Облако школы: настройка Firebase (бесплатный тариф Spark, карта не нужна)

Нужно один раз, делает администратор школы со своим аккаунтом Google. Занимает около 10 минут.

1. Откройте https://console.firebase.google.com → **Create a project** (название любое, например `chess-off-school`).
   Google Analytics можно отключить.
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**
   (Ники игроков превращаются в служебные адреса, настоящая почта не нужна.)
3. **Build → Firestore Database → Create database** → режим **Production** → регион на выбор
   (например `europe-west`) → Enable.
4. Вкладка **Rules** в Firestore → вставьте содержимое файла `firebase/firestore.rules` → **Publish**.
5. **Project settings (шестерёнка) → General → Your apps → Web (`</>`)** → зарегистрируйте приложение
   (Hosting не нужен) → скопируйте значения `apiKey` и `projectId`.
6. Впишите их в `firebase_config.json` в корне проекта:

       {"apiKey": "ВАШ_КЛЮЧ", "projectId": "ВАШ_ПРОЕКТ"}

   Ключ веб-приложения Firebase — не секрет, его можно хранить в репозитории: защита данных держится на
   правилах из шага 4.
7. Пересоберите веб-версию (см. README) и выложите. На экране выбора игрока появится кнопка
   «Онлайн-вход».

## Что хранится и кто что видит
- `players/{uid}` — ник, турнирный рейтинг, звание, число партий и кубков. Видят все вошедшие игроки.
- `private/{uid}` — полная копия профиля (статистика ходов, сильные и слабые стороны, дневник).
  Читать и писать может только сам игрок.

## Ограничения (честно)
- Рейтинг пишет клиент игры. В школе, где все друг друга знают, этого достаточно; от намеренной
  подделки рейтинга технически знающим человеком защиты нет (проверка на сервере потребует
  Cloud Functions и платного тарифа Blaze).
- Забытый пароль восстановить нельзя (почты нет): администратор создаёт игроку новый аккаунт
  в консоли Firebase (Authentication → Users) или игрок регистрируется под новым ником.
- Лимиты бесплатного тарифа для 30 человек не достижимы: порядка 50 000 чтений и 20 000 записей в день.
