# chessoff на shadcn/ui — демо

Отдельная версия интерфейса для сравнения с игрой на Godot: как выглядели бы главная, партия,
турниры, задачи, «Дорога домой», игроки школы, награды и выбор оформления на компонентах в стиле
shadcn/ui (Tailwind + токены shadcn, светлая и тёмная тема, акцентные цвета). Партия настоящая:
правила — chess.js, соперник — простой «жадный» бот. Данные — примерные.

Собрать: `python build.py` → `index.html` (страница для публикации) и `preview.html` (для просмотра
в браузере с локального сервера: `python -m http.server` в этой папке).

Это макет, а не перенос игры: shadcn/ui — компоненты React, в Godot их не встроить.
Плюсы, минусы и план перехода — на вкладке «Сравнение с Godot».
